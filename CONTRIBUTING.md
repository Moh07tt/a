# Contributing | المساهمة

Thank you for helping improve Mohammed Al-Safi Cyber Intelligence.

## Guidelines

- Keep the dashboard free to access and compatible with GitHub Pages.
- Preserve the Arabic and English interface.
- Prefer authoritative public sources and link to the original publisher.
- Include publication dates and distinguish confirmed facts from unverified claims.
- Do not publish personal data, credentials, API keys, or private incident information.
- Do not add offensive scanning, exploitation, or unauthorized access features.
- Keep changes small and test the website locally before opening a pull request.

## Pull requests

Describe the problem, summarize the change, list the files affected, and explain how you tested it. For intelligence data or claims, include the original public source.
